# Changelog

## 1.0.0 - 2026-11-09

First public release.

- 32 tools across five groups: Classroom, On-screen, Quiz games, Teacher and Learner.
- Starts in the notification area; optional "Start with Windows" and "Show window when starting".
- Plain-text class lists, question sets, statement banks and quote lists, with Edit, New and Import in each tool.
- Portable mode using a `Data` folder beside the program.
- Builds with the C# compiler included in Windows (`build.bat`), or with the included `.csproj`.
- Released under the MIT licence.
