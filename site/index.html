The little tools a lesson needs, in the corner of your screen.

A countdown on the board, a fair way to pick who answers, traffic lights for noise, a quiz for the last ten minutes. Classroom Toolkit puts 32 of them one click from the clock, made to be read from the back of the room.

Download for Windows

Free for Windows 10 and 11. Nothing to install.

Silent – working alone

Try it: click a light, or press R, A or G.

One small program. A single file smaller than most photos. No installer, no administrator rights, nothing else to set up.

Your own lists. Class lists, quiz questions and report statements are plain text you can edit, import and share with colleagues.

Nothing leaves the room. No accounts, no tracking, no internet connection. Everything stays in your Documents folder.

On the board

Drag any tool onto the projector screen and press F11. The buttons tuck themselves away until you need them.

Ready for a whole school

Classroom Toolkit is one exe that writes only to each user's Documents folder, so it's easy to roll out to every classroom. Copy it to each PC or run it from a share, and start it at sign-in for the staff who need it.

  • Runs without administrator rights, on Windows 10 1809 (LTSC 2019) and later
  • Starts quietly by the clock, and only one copy ever runs
  • Settings follow staff with folder redirection
  • Open source under the MIT licence, so you can check every line
Read the deployment guide

Get started in a minute

  1. DownloadGet the zip from the button at the top of this page, and extract it anywhere.
  2. Run itOpen ClassroomToolkit.exe. If Windows says it's from an unknown publisher, choose More info, then Run anyway.
  3. Pick a toolClick the traffic-light icon by the clock. Right-click it and tick Start with Windows to have it ready every day.

Questions

Is it really free?

Yes. It's open source under the MIT licence: free to use, copy, change and share, in schools and anywhere else.

Does it work on a Mac, Chromebook or tablet?

No. It's a Windows program, for Windows 10 version 1809 or later and Windows 11.

Where are my class lists kept?

In Documents\Classroom Toolkit, as plain text files. Right-click the icon and choose Open my lists folder to see them. To keep everything on a USB stick instead, make an empty folder called Data beside the program.

How do I update to a new version?

Right-click the icon by the clock and choose Exit, then replace ClassroomToolkit.exe with the new one. Your lists and settings carry over.

Can I suggest a tool or report a problem?

Please do. Open an issue on GitHub and tell us about the lesson moment it would help with.
