# Classroom Toolkit branding

| File | Use |
|---|---|
| `icon.svg` | App icon (40 px and up) |
| `icon-small.svg` | App icon for 16 to 32 px: wider housing and bigger lights, so it reads by the clock |
| `logo.svg` / `logo-dark.svg` | Icon and wordmark, for dark / light backgrounds |
| `wordmark.svg` / `wordmark-dark.svg` | Wordmark alone |
| `png/` | Icon at 16 to 1024 px, and the logo at 192 px high |
| `../app.ico` | The Windows icon built into `ClassroomToolkit.exe` (16 to 256 px) |

The icon is a traffic light, the most-used tool in the box, on a blue tile.
Colours match the app's theme (`src/Ui.cs`): blue `#3884ff`, housing
`#10161f`, red `#ef4444`, amber `#f59e0b`, green `#22c55e`; text `#12161e` on
light backgrounds and white on dark.

Everything here is generated by `make_branding.py`; run `./build.sh` to rebuild
the SVGs, every PNG size and `assets/app.ico`. It needs Python 3 with
fontTools and Pillow, `rsvg-convert` (librsvg) and the Inter font. The wordmark
is set in Inter Display SemiBold and converted to outlines (Inter is under the
SIL Open Font License, which allows this).

The artwork is part of the project and shares its MIT licence.
