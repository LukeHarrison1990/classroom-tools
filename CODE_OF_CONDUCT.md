# Code of conduct

Classroom Toolkit is a friendly place for teachers, support staff, IT
technicians, developers and anyone else who wants to make good classroom
tools freely available, whatever their experience, background or identity.

**Expected:** be kind and patient, assume good intent, give feedback about
the work rather than the person, and help newcomers find their feet.

**Not acceptable:** harassment, insults, discriminatory jokes or language,
personal attacks, publishing someone's private information, or sustained
disruption of discussions.

**If something goes wrong:** contact the maintainer privately (see the
repository owner's profile for contact details). Reports are kept
confidential. The maintainer may remove comments, code or issues, and may
block people who don't follow this code, in the project's issues, pull
requests, discussions and any other project space.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
