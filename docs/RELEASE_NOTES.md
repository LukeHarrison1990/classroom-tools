First public release of Classroom Toolkit: a free, open-source set of 32 classroom tools for Windows.

**Download** `ClassroomToolkit-1.0.0.zip` below, extract it and run `ClassroomToolkit.exe`. Nothing to install and no administrator rights needed. It starts in the notification area beside the clock; click the icon to open the tools.

**Requirements:** Windows 10 version 1809 (LTSC 2019) or later, or Windows 11. Uses the .NET Framework already built into Windows.

**Included tools**
- Classroom: Countdown Timer, Interval Timer, Stopwatch, Exam Clock, Traffic Lights, Random Student Picker, Dice, Random Number, Scoreboard, Plenary Prompts, Learning Outcomes, Key Words, News Ticker
- On-screen: Draw on Screen, Spotlight, Reading Guide, Cover-up
- Quiz games: Flash Cards, Noughts and Crosses Quiz, Four in a Row Quiz, Grid Quiz
- Teacher: Sticky Notes, Register Reminders, Exam Countdown, Learn Student Names, Report Statement Builder, Special Characters, Text Tidy
- Learner: Text to Speech, Speed Reader, Breathing Exercise, Quotes and Goals

Windows may warn that the file is from an unknown publisher because it is not code-signed. Choose **More info**, then **Run anyway**.
